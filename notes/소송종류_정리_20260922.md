# 소송 종류 총정리 (2026-09-22 질문 모음)

## 0. 전체 지도
- **항고소송** (행정소송법 §4): 취소소송 / 무효등확인소송 / 부작위위법확인소송 — 대상 = **처분**, 피고 = **처분청**
- **당사자소송** (§3 2호): 공법상 법률관계 자체 — 피고 = **국가·지자체·공단 등 권리주체**
  - 실질적 당사자소송(연금 미지급분, 공법상 계약, 지위확인)
  - 형식적 당사자소송(보상금증감청구소송)
- **민사소송**: 사법상 법률관계(사법상 계약, 부당이득, 소유권)
- 민중소송·기관소송(객관소송, 법률에 정한 경우만)

## 1. 3단 판별
1) 다툴 **처분**이 있나? → 있으면 항고소송
2) 권리가 **이미 확정**됐고 이행만 안 되나? → 당사자소송
3) **사인도 가질 수 있는 권리**(소유권·계약·부당이득)인가? → 민사소송

## 3. 대조쌍 암기
- 깎아주면 **원처분** / 새로 다 계산하면 **새 처분**
- 같은 의무 두 번 집행 **불가**(대집행 vs 민사철거) / 다른 권원 **병존**(변상금 vs 부당이득)
- 결정 전 **항고** / 결정 후 **당사자**
- 국가가 손님으로 살 때 **사법** / 공적 지위를 줄 때 **처분·공법상 계약**
- 대집행 O = 대체적 작위의무 / 대집행 X = **인도·명도**, 부작위, 수인의무
